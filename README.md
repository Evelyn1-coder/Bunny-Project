# Everybunny Loves Data

A Tableau project exploring rabbit adoption data. The workbook brings adoption records into an interactive view so readers can explore patterns and ask follow-up questions about the animals and their adoption outcomes.

## Explore the workbook

Download [Bunny project - Tableau.twbx](Bunny%20project%20-%20Tableau.twbx) and open it in Tableau. Use the workbook's views and filters to compare groups and inspect the underlying patterns.
